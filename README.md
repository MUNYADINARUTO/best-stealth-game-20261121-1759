Emberfox — The Quiet Heist: a top-down stealth game where a little fox sneaks through three guarded halls, hiding in bushes and behind crates, dodging vision cones, tossing coins to lure the night watch away, and slipping through the green exit door unseen.

## Run it

```sh
cd game && python3 -m http.server 8080
```

Then open http://localhost:8080 in desktop Chrome. Move with WASD or the arrow keys, hold Shift to sneak, click the floor to toss a coin and distract a guard, M to mute, P to pause.
